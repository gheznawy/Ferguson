# Ferguson & Sons Mechanical LLC — Sitemap

## Purpose of this document

This file defines the approved website architecture for Ferguson & Sons Mechanical LLC. It is intended to be used alongside `business.md` and `design.md` as a source of truth for design, content, implementation, internal linking, and future SEO expansion.

The site should remain simple and easy for customers to navigate while still supporting dedicated service and service-area pages for search visibility.

The sitemap is intentionally deeper than the main navigation. Not every page should appear in the header.


# 22. Cross-document source-of-truth rules

Use each project source for its intended domain:

1. **`business.md`** — authoritative for business facts, services, plan pricing/details, hours, reviews, coverage, phone, claims, and company positioning.
2. **`sitemap.md`** — authoritative for URLs, page hierarchy, navigation, page roles, internal linking, and planned SEO architecture.
3. **`design.md`** — authoritative for reusable visual tokens, components, layout, typography, colors, imagery treatment, responsive behavior, and implementation rules.
4. **Approved Stitch screenshots** — visual references for exact approved homepage composition, hierarchy, proportions, photography placement, and section feel.
5. **Original high-resolution assets** — production source for photos, logos, and media.

Do not let generated placeholder content or a static mockup override verified business facts. If a screenshot's wording conflicts with `business.md`, use the verified wording while preserving the approved visual treatment.
